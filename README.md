## Introducere

### Tema aleasa

Scopul proiectului este crearea unei platforme mobile in cadrul careia utilizatorii sa isi poata inregistra cartile intr-o "biblioteca" virtuala.

Utilizatorilor le este permis sa dea o nota cartilor pe care le-au citit, acest proiect ajuta cititorii pasionati sa tina evidenta cartilor citite 
si sa isi organizeze mai usor biblioteca, atat cea fizica cat si cea virtuala.

### Inspiratia proiectului

Inspiratia proiectului apare din site-uri web existente pentru managementul cartilor citite precum "Goodreads", "The StoryGraph" sau "Hardcover", 
dar si alte platforme de inregistrare a bunurilor intelectuale consumate precum "RateYourMusic", "Letterboxd" sau "MyAnimeList".
